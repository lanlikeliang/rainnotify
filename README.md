# 雨课堂助手

面向普通版雨课堂与 Android 16 的独立辅助 App，目标是切换 App、锁屏后仍能通过系统通知提醒课堂新题。

当前开发版本为 0.0.19-api-five-types：加入单选、多选、投票、填空和文字主观题的答案校验与提交格式，主观题默认简短回答；接入 DeepSeek 视觉 API；首页整理为课堂、自动作答、题目与统一设置入口。配置不全时保持功能关闭并给出设置路径。API Key 由用户在手机输入并加密保存，不需要无障碍服务或解锁。用户已完成真实 API 图文自检，历史题及短时熄屏后台演练完成；声音提醒仍需结合手机设置与用户反馈判断。详见[实现与验证记录](docs/五种题型与DeepSeekAPI-0.0.19.md)和[安装使用说明](docs/0.0.19-安装与使用.md)。

保留 0.0.18 截屏与入课改进：普通课堂可直接尝试入课并监听。服务器返回 50070 时提供扫码后继续入口，动态二维码签到仍需扫描教师当前展示的二维码。扫码返回只接续一次，不重复轮询入课；真实扫码返回与课堂连接仍待现场验证。

保留 0.0.17 题目身份校验修复：已知普通版题图域名的 `auth_key` 刷新不再阻止流程；题型、题干、选项映射、原图资源路径及其他图片参数仍严格比较。课后只读获取题目曾返回 HTTP 401，尚未取得真实新旧副本，修复后的真实课堂提交仍待下一次实课验收。

保留 AI 更新后图文自检：可以在「AI 设置 → 所选 AI 更新后图文自检」自行验证单选一图、多选两图，检查自动分享、发送、答案回读和已知图像答案。两项通过后可使用该安装版本，不再用固定版本号拦截。验证绑定具体安装与适配规则，更新后重新验证；未验证时仍可手动演练历史题。运行权限检查仍只针对雨课堂辅助 App，不要求 AI App 自启动或预先留在后台。

Kimi 3.1.4 已在 Xiaomi 14 上完成单图冷启动与双图自检，约 10.9 秒、11.2 秒；历史课堂单选题重试约 12.2 秒成功，此前一次约 60 秒失败，具体原因未留存，不能据成功重试推断稳定性已解决。自动模式开启前显示安全锁屏限制；本版不保存或代输锁屏密码。

保留题干、选项、原图、ZIP 导出、单题 AI 演练及本次课堂自动模式。0.0.13 在 Xiaomi 14 上验证过三款 AI 的演练；熄屏事件自动亮屏并经用户解锁后完成 Kimi 作答约 22.3 秒。同一道多选题曾出现模型答案不一致。真实雨课堂提交、长时后台联网、多品牌机型仍待验收。

普通版登录、会话恢复、课堂查询、真实监听，以及浏览 QQ 时的新题提醒已在 0.0.9 验证。优先纯手机运行；DeepSeek API 已接入，GLM 等其他 API 可继续扩展。
