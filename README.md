# 雨课堂助手 RainNotify

适用于 **Android 16、普通版雨课堂**的独立辅助 App。开启课堂监听后，可接收新题通知、保存题干与原图，或通过 DeepSeek API 自动作答并提交；课后按课堂导出离线复习笔记。

**[下载正式版 APK · v0.1.3](https://github.com/lanlikeliang/rainnotify/releases/download/v0.1.3/RainNotify-0.1.3-25.apk)** · [最新版本与更新说明](https://github.com/lanlikeliang/rainnotify/releases/latest) · [安装指南](docs/INSTALL.md)

手机用户下载 Release 中的 **`.apk` 文件**即可安装，无需下载 Source code，也无需电脑、Android Studio 或 USB 调试。已有正式签名版本可直接覆盖安装，建议先导出需要保留的课堂笔记，**不要先卸载旧版**。

本项目是独立辅助工具，并非雨课堂官方应用。

## 适用环境

| 项目 | 要求与范围 |
| --- | --- |
| 手机系统 | 最低 Android 16（API 36）；主要实测机型为 Xiaomi 14 / Android 16。其他品牌与后续 Android 版本尚未全面验证。 |
| 雨课堂 | **普通版雨课堂**；需要本人微信授权，并在微信扫描老师的课堂二维码入课。荷塘、长江、黄河版及学校专属入口未适配。 |
| 网络 | 手机可持续访问雨课堂；自动答题还需能够访问 DeepSeek API。 |
| AI 服务 | 当前接入 DeepSeek 官方 API，自动答题需自行配置有可用额度的 API Key；仅发题通知无需 API Key。 |
| 安装方式 | 直接安装 APK；不支持 iOS、Android 15 及更早版本。 |
| 后台运行 | 必须配置**本 App**的通知、省电策略与自启动；无需安装 Kimi、DeepSeek 或豆包 App，无需无障碍、悬浮窗或 AI App 关联启动权限。 |

API 由手机直接调用，不需要自行部署服务器。正常运行时可切换到其他 App 或熄屏，API 作答不要求亮屏、解锁或切换至 AI App。长时间休眠效果仍取决于手机后台策略和网络，不能把熄屏运行理解为始终在线的保证。

## 第一次使用

### 1. 安装与系统配置

下载并打开 APK，按系统提示允许当前浏览器或文件管理器安装应用。安装后，在 App 的「设置」中完成以下配置：

| 配置入口 | 应开启的选项 | 用途 |
| --- | --- | --- |
| 设置 → 通知与声音 | 允许通知；开启题目提醒及结果提醒渠道；按需开启悬浮通知、锁屏通知、声音和振动 | 接收新题及处理结果。 |
| 手机声音设置 | 调高**通知音量**；检查静音、勿扰和通知渠道是否静音 | 通知权限开启不代表一定有声音，媒体音量也不等于通知音量。 |
| 设置 → 后台运行 → 系统应用设置 | 将本 App 的省电策略设为**无限制 / 不限制**，允许后台活动和后台联网 | 降低熄屏后暂停监听、延迟处理的概率。 |
| 手机自启动设置 | **允许雨课堂助手自启动**，有后台自启动选项时一并开启 | 降低系统清理或限制后台运行的概率；各品牌菜单名称可能不同。 |

小米 / HyperOS 请重点检查「应用省电策略 → 无限制」和本 App 的自启动开关。若横幅时有时无，再检查系统的悬浮通知临时屏蔽。自启动授权不等于开机后自动选择课堂；重新启动 App 后仍应确认课堂连接和模式。

Android 的通知授权与系统通知渠道共同决定提醒效果，详见 [Android 官方通知权限说明](https://developer.android.com/develop/ui/compose/notifications/notification-permission)。

### 2. 授权账号并连接课堂

1. 在「课堂 → 当前账户」生成微信授权二维码，按页面提示保存二维码，在微信扫一扫中从相册识别并确认授权，然后返回本 App。
2. **用微信扫描老师展示的课堂二维码**，在微信确认已进入课堂。账号授权成功并不等于已进入本节课堂。
3. 返回「当前课堂」，刷新并选择对应课堂，点击「我已扫码，连接此课堂」。保留课堂选择，是为了在有多个课堂时明确监听目标。
4. 等待 App 显示「课堂已连接」，再选择所需模式。课程名称与班级名称由雨课堂接口提供；缺少字段时显示现有名称或历史课堂标识。

「课堂已连接」表示服务端已确认监听连接，**签到是否成功以微信雨课堂为准**。获取监听凭据的现有接口可能刷新签到记录，连接前的确认框会说明；本 App 不替代扫码入课。

### 3. 选择使用模式

课堂页的大按钮为三选一，同一时间只启用一种模式：

| 模式 | 行为 | 额外要求 |
| --- | --- | --- |
| **关闭** | 停止监听与后续自动处理；仍可浏览已有课堂笔记和设置。 | 无需登录或配置 API 即可查看本地内容。 |
| **发题通知** | 监听当前课堂，提醒新题并保存题干、选项、原图。 | 账号授权、扫码入课、课堂连接及通知 / 后台配置。 |
| **自动答题** | 在通知和保存基础上，自动获取完整题目、调用 API、校验答案并尝试提交。 | 以上条件，加上有效的 API Key 和**当前模型自检通过**。 |

缺少必要配置时，页面会指出需要补齐的项目。自动答题运行期间，重新自检或修改模型、密钥会提示先切回发题通知，不会因点击自检而静默改变当前模式。API 或后台条件失效时，可能停止自动答题并提示原因，需要处理后重新开启。

### 4. 配置 AI 服务（仅自动答题需要）

进入「设置 → AI 服务」，在手机中输入 DeepSeek API Key 并加密保存，选择模型，执行对应自检。通过后回到课堂页开启自动答题。自检会实际调用 API，费用由自己的 DeepSeek 账户承担。

| 当前内置模型 | 题目支持 | 自检 |
| --- | --- | --- |
| **DeepSeek Flash**（`deepseek-flash`） | 文字与图片，适合雨课堂题图。 | 图文自检。 |
| **DeepSeek V4 Pro**（`deepseek-v4-pro`） | 仅纯文字题。遇到含图题会提示切换 Flash，本题不继续提交。 | 文本自检。 |

每个模型单独验证，换模型后需要重新自检；不会为了处理图片而自动换模型。模型能力依据 [DeepSeek 官方模型说明](https://api-docs.deepseek.com/quick_start/pricing/)与[图文接口说明](https://api-docs.deepseek.com/guides/vision/)，核对日期为 2026-10-28。服务商模型与计费可能调整，以官方说明和 App 当前自检结果为准。

## 功能介绍

### 课堂与新题提醒

- 课堂页集中显示当前账号、课程 / 班级、所选模型及三档模式。
- 最新题摘要显示**本机收到时间、题型、AI 答案和处理状态**；点击可查看完整题目。收到时间不冒充教师端的精确发布时间，断线补收会标注。
- 通过系统通知提示新题与处理结果，支持声音、振动和锁屏展示，实际呈现受系统设置控制。
- 每次监听一个课堂。课堂结束或单次监听达到 4 小时后停止，需要时重新连接。

### 五类题目与自动作答

| 题型 | 当前实现 |
| --- | --- |
| 单选 | 校验选项映射，提交一个选项。 |
| 多选 | 校验多个选项及重复项，再提交选项集合。 |
| 填空 | 按空格顺序返回答案，校验空格数量，保留不同空中的相同答案。 |
| 投票 | 遵守题目可选数量限制；个人偏好、个人事实或调查意愿不由模型代替用户决定。 |
| 主观 | 支持文字答案，要求言简意赅，默认 1～3 句且不超过 300 字符；需要画图或音频的回答不支持。 |

五题型已具备客户端处理与合成流程测试，不代表所有真实课堂题型均已完成验收。独立的判断题协议尚未完成实际提交验证，不在本版自动提交支持范围中。

自动作答包含题目完整性检查、答案格式校验、提交前状态复核和重复提交保护。只有收到雨课堂确认才显示提交成功；「已有作答」不代表本次 AI 答案被采用，「提交结果待确认」需要到微信核对，**不会自动重复发送结果不明确的提交**。关闭功能可以取消后续处理，不能撤销服务器已经收到的请求。

### 连续发题与断线恢复

新题按接收顺序排队，避免正在作答时直接丢弃后续题目；排队沿用原题时限。重连后尝试从服务端时间线补收未见题目，已结束的题目仅保存供复习。网络中断、系统杀进程、模型响应过慢或作答时间不足仍可能导致未处理或未提交，不能保证所有情况下零漏题。

### 课堂归档与复习导出

- 「题目」按课堂保存收到的题目；发题通知和自动答题两种模式都会记录。
- 保存题干、选项、原图，以及已取得的 AI 答案、实际使用模型和处理状态。
- 原图支持页面查看和全屏查看。新版不再按“最近 20 题”自动淘汰旧题，实际容量仍受手机存储空间限制。
- 在课堂题目列表点击「导出课堂复习笔记」，保存**单个 HTML 文件**；原图嵌入文件，可离线打开、折叠答案自测，也可通过浏览器打印为 PDF。
- 旧版未保存的课程名、答案及已清理图片无法恢复。AI 答案不是教师标准答案，复习时应自行核对。

### 账户与数据

API Key 使用 Android Keystore 加密保存在本机。API 模式会把本题必要的文字、选项和图片发送至 DeepSeek；账号授权、课堂监听和答案提交与雨课堂交互，不经过本项目自建服务器。

「设置 → 关于与帮助」可导出脱敏诊断，用于反馈故障；诊断不包含题干、答案、登录票据或 API Key。课堂复习笔记则包含题目与答案，应由用户自行决定如何保存和分享。清除应用数据或卸载会丢失本地配置和题目，升级请直接覆盖安装。

## 常见问题

**有通知但没有声音？** 检查通知音量、静音 / 勿扰、题目及结果渠道的声音开关。只调高媒体音量通常不够。

**熄屏后延迟，解锁才有提示？** 检查本 App 的省电策略是否为无限制、自启动是否允许、后台网络是否受限；不要强行停止 App。不同品牌仍需实际验证。

**已登录但不能连接课堂？** 先在微信扫码入课，再回本 App 刷新并选择同一课堂；课堂可能已结束，也可能需要重新授权。App 不自动代替用户扫码。

**自动答题为什么没有提交？** 查看最新题状态。常见原因包括题目结束、剩余时间不足、模型无法可靠回答、图片未就绪、账号已作答或提交结果待确认；具体原因以页面提示为准。

**能否使用 DeepSeek App 的会员或登录状态？** 不能代替 API Key。本版只通过 API 工作，不调用手机 AI App；API 额度由服务商单独管理。

**安装提示签名不同？** 请确认正在更新同一正式包。正式版包名为 `cn.rainnotify.app`，早期 `.debug` 预览版是另一个应用。自编译签名也与发布签名不同，不要为解决提示直接卸载仍有重要数据的旧包。
