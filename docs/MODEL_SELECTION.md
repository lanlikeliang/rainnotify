# 0.1.2-internal：界面简化与模型选择

日期：2026-10-27。

## 产品变化

- 删除“当前连接，一目了然”“本次课堂 · 最新一题”；正常关闭监听不再追加底部提示，连接错误与课堂扫码提示仍保留。
- 应用图标改为雨课堂图形的黑底白色版本，来源见 ICON_SOURCE.md。
- 设置 → AI 服务 → 当前模型可选择 DeepSeek Flash 或 V4 Pro；课堂与设置显示当前选择，题目结果保存实际使用的模型。
- Flash 支持图文；V4 Pro 仅支持文字。Pro 遇到含图题在 API 请求前拒绝，并提示切换 Flash；不自动换模型，不剔除图片继续作答，不提交。
- 模型切换保存于本机，并关闭自动答题、使当前自检失效。Flash 做单图/多图自检，Pro 做纯文字单选/多选与 JSON 格式自检。只有当前模型通过自检后才能重新开启自动答题。
- 保持现有非思考模式、60 秒模型请求上限、总流程截止时间和提交防重逻辑。模型选择不改变雨课堂入课/提交接口。

## 官方依据

DeepSeek 官方模型表：https://api-docs.deepseek.com/quick_start/pricing/ （2026-10-27）
图文接口：https://api-docs.deepseek.com/guides/vision/

使用真实模型 ID `deepseek-flash`、`deepseek-v4-pro`；旧 Flash 名称只是别名，不列成不同模型。

## 验证边界

使用本地 MockWebServer 和合成题验证选择的模型进入请求、Pro 含图不发请求、纯文字自检样本、结果模型归属，以及现有协议/取消/防重回归。设备测试增加模型选择、页面重建保留选择、切换使旧自检失效的场景。

本轮不使用真实 API Key，不进行课堂提交。设备测试编译与真实运行分别记录在发布产物验证报告中。
