# 志愿者安装与题目采集（0.0.11）

日期：2026-10-12。文件：RainNotify-0.0.11-Android16-test.apk，约 7.8 MB。

本版用于普通版雨课堂的真实题目内容核验：新题提醒、获取题干/选项/原图、离线查看和手动导出 ZIP。AI 作答和答案提交尚未接入。

## 安装

1. 确认手机为 Android 16（API 36）。Android 15 及更早版本无法安装；其他更新版本尚未验证。手机品牌不限，但目前只在 Xiaomi 14 验证过登录、监听和提醒，其他品牌需要实测。
2. 把 APK 保存到手机，从文件管理器打开。若系统提示，只为此次打开 APK 的应用授权“安装未知应用”；安装后可关闭该授权。无需 USB 调试、Root 或无障碍权限。
3. App 名称为“雨课堂提醒·通知验证”。已有同一项目旧版时可直接覆盖安装，无需卸载；新安装需要登录自己的账号。
4. 在首页启用系统通知，打开题目提醒设置，确认声音/振动；在 App 通知设置中开启需要的悬浮、锁屏通知。若通知静音，检查手机响铃模式、勿扰与通知音量。
5. 允许本 App 在后台运行，放宽本 App 的电池限制。小米/HyperOS 将应用省电策略设为“无限制”；其他品牌按各自设置检查。可先做一次“30 秒后测试”：按电源键熄屏，等待至少 50 秒，记录屏幕关闭期间是否有声音。模拟成功还需要真实课堂验证。

这是调试签名的项目测试 APK，未作为应用商店正式版发布。0.0.11 已完成构建、签名及 Manifest 校验，45 项 JVM 测试通过；系统文件保存界面和真实题目内容仍需手机实测。

## 课堂采集

1. 点击“普通版雨课堂登录与课堂监听”，生成授权二维码并保存。用微信扫一扫，从相册选择本次二维码并授权；回到辅助 App 确认已登录。不要向项目人员发送登录二维码、密码或 Cookie。
2. 在微信里正常进入课堂。在辅助 App 选择当前课堂，点击“监听此课堂”，按界面说明手动“获取令牌并监听”。该步骤可能记录签到；重连和题目内容读取不会重复调用入课。
3. 看到“课堂连接已确认，正在监听新题”后，等待老师自然发题。只采集监听开始后的实时新题，不补抓历史题。
4. 点击新题通知或“最近题目 · 题干、选项与原图”，等待内容保存。对照微信核验题型、题干、每个选项和原图；原图可双指放大。
5. 若图片失败，可在仍监听同一课堂时重试；下课后停止监听。最近 20 题可离线查看，缓存约 80 MB，超限会清理较旧记录，请及时导出。

题干/选项有时全部绘制在课件原图内，因此文字为空并不必然是获取失败。本版没有 OCR；判断题字段等题型映射仍待样本确认。

## 导出并发送给项目负责人

1. 单题详情点击“导出本题 ZIP”；最近题目列表点击“导出最近题目 ZIP”。建议等待图片下载完成。
2. 阅读范围说明，点击“选择保存位置”，在系统文件界面保存到手机的下载/文档目录。
3. 等待“已导出…”提示。然后从手机文件管理器，把 rainnotify-questions-日期时间.zip 发给项目负责人；文件较大时，可按单题导出发送。
4. ZIP 包含题型、静态 HTML 题干/选项、已下载原图、获取状态，以及 App 版本、手机品牌/型号、系统 API 和时间。原图下载地址、账号信息、登录凭据和课堂接口标识不会导出。题目原图本身仍可能显示授课者/学校信息，请检查后发送。
5. 缺失图片、获取中或内容失败会在 question.json 中注明。capture_complete 只表示预期文件已保存，不代表题目已人工核验。导出失败时请换保存位置重试，不要发送没有成功提示的残缺 ZIP。

本 App 不会把样本自动上传给项目人员。首页“导出本 App 诊断报告”是另一种 JSONL 文件，供错误排查使用，不含题目正文和图片，不能代替题目 ZIP。

保存入口使用 Android 官方的系统文件选择方案，无需新增广泛存储权限。参考：[Android 官方文件保存指南](https://developer.android.com/training/data-storage/shared/documents-files#create-file)。

## 请随 ZIP 附上一条反馈

填写“手机型号 / Android 版本 / 大致发题时间 / 当时在本 App、其他 App 还是熄屏 / 通知和声音是否正常 / 题干选项原图是否与微信一致”。无需提供姓名、课程名或老师姓名。

例如：“Xiaomi 14 / Android 16 / 14:30 / QQ / 有声通知 / 单选，A–D 一致，完整题干在原图里”。失败时附界面错误描述；可另发首页的诊断 JSONL。

## 分发与更新

电脑内的 APK 文件路径不是志愿者可访问的互联网链接。项目负责人可将 APK 和本说明发送给志愿者，或放到自己选择的网盘后分享下载链接。本次未发布到外部网站，也未部署数据收集服务器。

后续升级需要保留相同签名；保留项目签名密钥即可持续覆盖安装。分发目录的 SHA256SUMS.txt 提供 APK 校验值，APK-info.json 记录版本、大小和公开签名证书指纹，不包含私钥。
