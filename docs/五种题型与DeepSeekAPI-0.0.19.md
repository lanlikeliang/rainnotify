# 五种题型、DeepSeek API 与使用入口整理

日期：2026-10-24。版本：0.0.19-api-five-types。

## 题型范围

参考项目中的《雨课堂参考资料》：PDF 第 32–34 页（印刷页 28–30）列出 PPT 课堂题目的五种类型。新版试卷还包含判断题；本次主要处理普通版课堂中的五种类型，不把试卷或考试当成课堂接口使用。

| 题型 | 模型答案与检查 | 雨课堂提交内容 |
| --- | --- | --- |
| 单选 | 一个存在的选项标签 | 标签数组 |
| 多选 | 不重复的有效标签 | 排序后的标签数组 |
| 投票 | 至少一项，不超过题目 pollingCount | 标签数组 |
| 填空 | 按 blanks 数量逐空填写，允许不同空答案相同 | 保持空格顺序的字符串数组 |
| 主观 | 一段文字，默认 1–3 句，不超过 300 字符 | content 文字及空图片占位 |

投票提示词要求：涉及个人意愿、个人经历或调查事实时不替用户编造，返回无法作答。主观题本期支持个人文字回答，不生成录音、手写图片；识别到分组事件时提示到微信完成，不代小组提交。判断题保留历史演练；正式提交格式仍待实课核验。题目缺少填空数量或投票限制时明确失败，不猜测规则。

空格数量和投票限制进入本机题目缓存及手动导出，并参与提交前的题目一致性检查。仅保留空格数量，不保留 blanks 中可能存在的教师参考答案。新旧样本兼容：旧样本缺少必要规则时提示重新采集。

核对公开官方学生网页资源，未操作账号或发出课堂提交：

- [课堂网页](https://www.yuketang.cn/lesson/fullscreen/v3/)
- [选择题与投票模块](https://fe-static-yuketang.yuketang.cn/fe/static/lesson/3.3.236/js/42.25af119259a848dfe5a2.js)：选项标签数组及投票数量。
- [填空模块](https://fe-static-yuketang.yuketang.cn/fe/static/lesson/3.3.236/js/46.05dddee875a2b20f80de.js)：空格顺序及 Object.values 形成的数组。
- [主观模块](https://fe-static-yuketang.yuketang.cn/fe/static/lesson/3.3.236/js/16.5bc07a946b68f7aeb868.js)：content/pics 对象，纯文字时图片字段为空。

公开网页格式是实现依据，不能代替真实课堂对服务端回执与答案显示的验收。

## DeepSeek API

通过手机直接访问官方 HTTPS 地址，无需部署服务器，无需安装 DeepSeek App。使用官方当前支持图文的 deepseek-flash，关闭深度思考以适应课堂时间限制，采用 JSON 输出。

- [视觉输入文档](https://api-docs.deepseek.com/guides/vision/)
- [JSON 输出文档](https://api-docs.deepseek.com/guides/json_mode/)
- [思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode/)

发送本题经过静态化的文字、选项和已保存的所有原图。图片使用本地字节编码，不发送雨课堂 Cookie、课堂标识或临时图片下载链接。应用限制最多 12 张、合计 24 MB、每边不超过 8192 像素，超限直接提示，不悄悄漏图。

API Key 在手机设置页输入，以 Android Keystore 加密后保存在不参与备份的目录；不回显，不进入诊断或题目 ZIP。服务地址固定为官方地址，不跟随重定向，不自动重试模型请求。错误提示不回显服务器正文。取消任务会取消正在进行的网络调用。

自检使用随机答案的本地测试图片，分别验证单图单选和双图多选。API 自检与 AI App 更新自检各自保存，不相互借用结果。密钥修改或删除会清除 API 自检状态。真实提交/自动模式需要 API 自检通过；历史题允许手动演练。

沿用最多约 85 秒的单题总预算、最多 60 秒模型等待、提交前再次读题及一次提交限制。API 自动流程直接进入后台作答服务，不经过亮屏/解锁页。仍受网络、本 App 后台权限、厂商省电与课堂剩余时间影响；短时熄屏演练通过不等于长期休眠可靠性。

## 新用户路径

1. 设置 → 通知与声音：允许通知、检查题目渠道与锁屏声音。
2. 设置 → 本 App 后台运行：允许本 App 自启动并调整省电策略。
3. 首页 → 课堂：登录、选择课堂并确认入课监听（可能记录签到）。
4. 只需提醒时到此即可。需要 AI 时，在设置中选择 API 或 AI App 并完成相应配置、自检。
5. 在“题目”中先演练；回到首页按需开启“新题自动作答并提交”。

开关只表示当前监听期间的授权。未监听或配置不完整时保持关闭，解释原因并提供对应入口。切换作答方式、下课或停止监听后关闭。API 不要求无障碍服务；App 路线仍要求解锁和本 App 的作答辅助授权。不会要求用户为第三方 AI App 设置自启动。

通知模拟与诊断导出移入设置。历史题查看、导入、演练及 AI 配置无需雨课堂登录；真实监听和提交需要当前课堂会话。

## 验证记录

已在 Xiaomi 14 覆盖安装。用户在手机自行输入密钥，反馈单图/双图 API 自检均通过并选择 API 模式；电脑未读取密钥。

历史题 API 演练：约 1.17 秒，结果 REHEARSED，live=false。30 秒延时模拟发题后的一次演练：约 1.17 秒完成，准备、求解、校验、结束四个阶段的 interactive 全部为 false，device_idle=false。表明该次短时熄屏期间后台求解完成，未要求解锁；不代表 Doze 深度休眠或长期课堂联网已验证。

最初用户反馈有结果通知、页面完成但无声音。随后用户确认之前未开启通知音量，打开后结果完成有声音。后读取的通知诊断为音量 5、正常响铃、非勿扰、题目渠道高提醒且声音/振动已配置。连续通知冷却曾作为待排查可能性，未认定为这次无声的原因。代码增加了结果通知发送状态与当时音量的脱敏记录，便于以后区分计算、通知送达和声音展示。

自动验证：114 项 JVM 测试通过，Lint 0 错误、60 警告、2 提示。覆盖五题型格式、空格顺序与重复答案、规则变更拦截、分组提交拦截、导出导入、API 图片完整性、取消、重定向不转发密钥、异常结果不提交，以及原有登录/监听/提交防重逻辑。APK 使用与旧版一致的签名，覆盖安装成功。

手机上的三道新增本地练习也已通过 API 完成，均为 `live=false`、`REHEARSED`，没有课堂提交：

| 本地练习 | 结果 | 处理时间 |
| --- | --- | --- |
| 客观知识投票，最多两项 | A、C，符合预设结果 | 约 1.23 秒 |
| 两个空格，分别填写史记、资治通鉴的作者 | 司马迁、司马光，顺序正确 | 约 0.64 秒 |
| 一句话说明交叉核对史料的原因 | “不同来源史料各有立场与局限，交叉核对可辨别真伪、减少偏误，更接近史实。” | 约 1.15 秒 |

这些练习保留在手机“题目”中并标为离线，仅供后续演练。不能把简单练习的耗时或准确率推广到所有实际课堂题目。调试入口受系统 DUMP 权限保护，不接收任意文本或真实提交参数。

真实课堂无法用历史演练替代，当前不自动入课或向已结束的课堂发送答案。三种新题型的真实提交显示、长期后台稳定性和其他品牌 Android 16 手机仍待验收。
