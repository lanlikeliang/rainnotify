发布日期：2026-10-28。versionCode 25，包名 `cn.rainnotify.app`，最低 Android 16（API 36）。

## 代码与构建范围

本版与 `0135c6698cbba9bd09a24e72fc06691a1d0b8604` 的 0.1.3-internal / 24 具有相同业务代码；本次仅更新版本标识和发布文档。正式签名继续使用原证书，允许覆盖升级。每个发布包的提交号、APK SHA-256 和签名摘要记录于 Release 附件，发布前从干净提交重新执行 Release 构建、单元测试和 Lint。

发布检查以 [GitHub Actions](https://github.com/lanlikeliang/rainnotify/actions) 的实际结果及 Release 的 `validation-summary.json` 为准。CI 只使用合成题和本地模拟服务，不接触真实账号、API Key 或课堂。

- Debug、Release 各 131 项 JVM 测试及 9 项 Python 测试通过。
- Lint 无新增问题，Debug 11 项 / Release 10 项既有问题已逐项审核。
- Xiaomi 14 / Android 16 上的 7 项隔离设备测试通过，覆盖模式互斥、缺项不启动、设置入口、模型状态、来源返回和自动模式自检保护。
- 正式签名包从 23 升至 24，启动正常，账号授权、当前模型自检和已有题目保留。
- 原图显示、点击进入全屏及课堂题目列表正常；用户确认课堂复习导出保存成功。双指缩放未单独验证。
- 合成复习 HTML 已在浏览器核对题干、选项、内嵌原图、答案和折叠交互。

上述真机证据来自 24 版，未将其标记为 25 版的新一轮真机测试。25 版以发布附件记录此次实际构建与检查结果。

## 持续验证事项

- 新课程名称及微信扫码后的课堂连接反馈。
- 连续发题、断线补收、长时间熄屏与各品牌后台策略。
- 五题型的全部真实课堂提交回执；合成测试不能替代服务端验收。
- 桌面图标在不同厂商上的大小与裁切。

服务器未返回的题目无法恢复；排队仍受原作答时限限制；提交结果不明确时不自动重试。AI 答案不等于教师标准答案。旧版已清理题目、未保存的课程名和答案无法补回。

本次公开发布不额外进入真实课堂、调用真实 AI API 或提交答案。早期工具链迁移过程保留于 [历史记录](VALIDATION_TOOLCHAIN_HISTORY.md)，其中旧 AI App 和演练路径已退出当前产品。
