# 多服务器适配（开发中）

初次适配记录为 2026-10-29 的 `0.1.4-internal / versionCode 26`。2026-11-06 的内部版本升级至 `0.1.4-internal / versionCode 27`，同时包含四服务器适配和参考答案流程修复。实现与最新验证见 [参考答案与提交分离](REFERENCE_ANSWERS.md)。公开版本为 v0.1.3 / 25。

## 使用顺序

1. 课堂 → 当前服务器／当前账户（或设置 → 雨课堂服务器），先选择学校或老师指定的服务器。
2. 选择普通版、长江、黄河或荷塘。首次打开及从 25 版升级均不代选；未选择时不恢复登录、不生成授权二维码。已选择的服务器会记住，下次打开只检查该服务器的保存会话。
3. 在所选服务器下生成微信授权二维码，在对应公众号完成授权。各服务器独立保存登录；退出只清除当前服务器的凭据。
4. 用微信扫描教师课堂二维码后，在 App 刷新课堂、选择同一课堂并确认连接。
5. 按需开启发题通知／自动答题。更换服务器前须先关闭监听，等待当前作答结束；登录过程中的服务器切换会取消旧二维码及旧网络回调。

长江、黄河、荷塘暂标为“测试支持”，不宣称已经完成真实课堂验收。账号和 Key 仍由用户在自己的手机上输入或授权。

## 实现与兼容

- 固定四个官方域名：`www.yuketang.cn`、`changjiang.yuketang.cn`、`huanghe.yuketang.cn`、`pro.yuketang.cn`。HTTP 接口、Referer、Origin、Cookie、登录和课堂 WebSocket 使用所选环境；不提供任意服务器地址输入。
- 保留现有扫码协议及课堂接口，没有引入未经实测的新 HTTP 登录流程。二维码图片只允许微信或所选服务器，不携带会话请求图片。
- 加密会话文件、Keystore 别名和加密上下文按服务器隔离。普通版继续使用 25 版原有文件、密钥和格式，不重建或清空。
- 监听启动携带服务器标识，并与当前选择核对。切换服务器时清空页面中的课堂选择和扫码确认；正在监听／作答时拦截切换。
- 归档增加服务器字段；旧记录缺少字段时按普通版读取。按服务器和课堂 ID 分组，列表、题目详情与 HTML 导出标明来源；不同服务器的同 ID 课堂不会合并。普通版原课堂键保留。
- 新服务器的提交防重作用域包含服务器；普通版沿用旧作用域算法，保留 `UNKNOWN`／进行中等全部防重记录，不清空 journal。
- 27 版比较图片实际内容，无法完成图片比较时按用户授权退回文字核对。下载来源继续限定在已允许的图片域名。
- 27 版先生成并显示参考答案，再检查自动提交条件。提供用户确认后的手动提交，保留账号、课堂定位与防重记录。

## 调研与匿名验证

官方手册列出四个服务环境：[学生手册](https://jwc.bucea.edu.cn/docs/2023-05/85320e65df2f4f35ad6b02aa88f74877.pdf)。本轮读取四个官方登录页，均引用同一版本的[登录脚本](https://fe-static-yuketang.yuketang.cn/fe/static/vue/2.2.681/login.js)。脚本包含新 HTTP 扫码及微信快捷登录流程，不能据此推断旧协议失效。

2026-10-29 的匿名协议检查：四个域名均成功连接 `/wsapp/`，对现有 `requestlogin` 请求返回相同的二维码字段集合，图片主机均为 `mp.weixin.qq.com`。未扫描二维码、未获取账号登录态、未进入课堂、未调用 DeepSeek 或提交答案；二维码及票据未写入项目。此证据只覆盖二维码签发，不能代表授权确认成功。
