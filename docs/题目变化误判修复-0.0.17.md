# 题目变化误判修复与验证（0.0.17）

日期：2026-10-21。设备：Xiaomi 14 / Android 16。

## 故障与证据

用户实课反馈反复出现“题目或选项发生变化”，多数在打开 AI 前，也有取得 AI 答案后出现。手机诊断与此一致：多次准备后立即失败，两次求解后进入校验阶段再失败。

代码原先把 `QuestionContent.json()` 整体序列化后求摘要，用它判定题目是否变化。这个对象包含图片完整下载地址、页面位置和解析提示。当天缓存题图来自 `rain-pri-ups.yuketang.cn`，地址带 `auth_key`。因此即使题目和图片没变，只要临时访问凭据刷新，旧逻辑也会拒绝；两个校验节点共用该逻辑，可以解释两个失败时点。

已用回归样例确认：相同题目仅改变该参数，旧比较结果不相等，新比较结果相等。阿里云官方说明 `auth_key` 含时间戳、随机数和签名，CDN 会移除鉴权参数定位缓存资源，支持将访问授权与资源身份区分：[鉴权方式 A](https://help.aliyun.com/zh/cdn/user-guide/type-a-signing)、[URL 鉴权](https://help.aliyun.com/zh/cdn/user-guide/configure-url-signing)。这说明机制，不单独证明本次每一道实课题的失败原因。

真实新旧副本比对未完成：修复版安装后，使用手机内已有会话只读请求最近三道题，均返回 HTTP 401；用户确认课堂已经结束。尚不能证明当天每次失败都仅由签名刷新造成，也没有取得原图字节一致性的实机证据。未调用进入课堂或提交接口来绕过此限制。

## 修复范围

- 两处校验统一使用 `QuestionIdentity` 比较作答相关内容。
- 仅对 HTTPS 默认端口、无 URL 用户凭据、精确域名 `rain-pri-ups.yuketang.cn` 的图片地址，比较时去掉 `auth_key`。下载仍使用完整签名地址。
- 支持原图资源列表和题干、选项 HTML 内真正的 `img src`；不处理其他属性、普通文字、其他域名的同名参数。
- 页面位置和解析提示不影响答案映射，不再纳入内容身份。
- 题型、题干、选项标签/键/顺序/文字、图片角色/顺序/数量/路径及未知查询参数继续严格比较。真实变化仍停止。
- 保留课堂连接、收题/剩余时间、账号已答、重复提交记录和不确定回执不重试等检查。
- 记录 `answer_content_check`，区分 `before_solve` / `before_submit`，只保存差异类别和一致性标志。日志不保存题干、答案、图片地址或签名。

本次未改动 AI 适配规则版本，不主动清空此前已通过的 AI 安装版本自检记录。未接入新的模型 API，也未改变安全锁屏行为。

## 验证结果

构建、95 项 JVM 测试通过；Lint 0 错误、59 警告、2 提示。APK v2 签名验证通过，与已有安装签名一致。0.0.17 已通过 USB 覆盖安装到 Xiaomi 14。

新增 13 项测试，覆盖：

- 原图签名更新、题干和选项内图片签名更新、页面/提示变化、序列化顺序。
- 真正的题干、题型、选项映射/顺序、图片路径/角色/数量/参数变化仍阻止提交。
- 仿冒域名、带用户凭据/非标准端口的地址及普通属性文字不会被当作可忽略签名。
- 同一题在 AI 前、AI 后两次签名刷新，可以完成一次模拟提交；再次运行不会重复提交。
- 真实解析器和 `RainApi` 对接本地模拟服务器：单选、多选分别执行两次 GET 和一次 POST，得到模拟成功回执。模拟服务器不代表雨课堂线上已接受答案。

这次没有向真实课堂发送答案。最终验收仍需下一次自然发题，核对服务器成功回执与微信中实际作答状态。

## 复核工具

在项目根目录使用已授权 USB 设备：

```powershell
.\tools\compare_question_snapshot.ps1
.\tools\compare_question_snapshot.ps1 -ReadResult
.\tools\read_answer_state.ps1
```

只读比较入口仅存在于 debug 构建，受系统 DUMP 权限限制；它在手机内恢复登录会话，只请求已缓存题目的内容和第一张原图，不登录、进入课堂、调用 AI 或提交。输出为比较标志和固定错误类别，不导出凭据或内容。在线访问是否允许仍由雨课堂决定，401 不能当作题目变化。

下次实课先确认辅助服务与所选 AI 自检状态，手动重新开启监听及本次课堂自动模式。若仍失败，使用新增诊断确定具体字段；若显示提交成功，首次需在微信核对答案是否落地。不要因结果不确定而重复提交。
