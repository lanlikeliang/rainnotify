# API 正式界面内部验证包安装

0.1.1-internal，最低 Android 16（API 36）。这是正式版产品界面的内部验证包，尚未完成本轮真机与课堂回归。

正式签名包为 `cn.rainnotify.app`，预览包为 `cn.rainnotify.app.debug`，可并存。从预览版首次安装独立正式包，需要重新授权账号、配置 API Key 和通知。已有正式包覆盖升级保留自身数据。旧版课堂原件不删除，但新版不提供历史题库或 ZIP 导入入口，需要的旧导出请自行归档。旧 API 自检记录需在当前模型下重新验证，密钥不回显。

先对照同目录 SHA256SUMS.txt 检查 APK，再用手机文件管理器打开 APK 并允许该来源安装。以后安装同签名且版本号更高的 APK 可直接升级，避免先卸载造成数据丢失。

1. 课堂页点击“当前账户”，生成并保存授权二维码；在微信扫一扫中选择该图片并授权，返回 App。
2. 选择正在上课的课堂。这里仅选择，开始模式时才发起入课，界面会提示可能记录签到。学校要求扫码时仍需按提示在微信完成。
3. 设置 → 通知与声音，允许系统通知并确认通知音量；设置 → 后台运行，按手机情况解除本 App 省电限制、允许自启动。无需安装 AI App 或开启无障碍、关联启动。
4. 只需提醒时选“发题通知”。需要自动答题时，先到设置 → AI 服务输入 DeepSeek API Key，完成图文自检，再选“自动答题”并确认。
5. 题目页展示最新题与处理状态。“AI 答案”不代表提交成功，以“已提交 · 雨课堂已确认”为准；结果待确认时到微信核对，不重复发送。

三档控件随时可切回通知或关闭。仅处理开启后收到的新题，进程结束后不会恢复自动提交。关闭不能撤回服务器已经收到的入课或提交请求。图文自检会调用当前 API 并可能计费，不向课堂提交。

本包已通过合成数据回归与构建检查，仍需真机检查布局、点击、扫码返回及课堂链路，不能仅凭安装成功视为稳定版。

遇到问题可从设置 → 关于与帮助导出脱敏诊断；其中不应包含题干、答案、登录票据或密钥。不要通过聊天发送密钥。
