# 内部验证包安装

仅支持 Android 16（API 36）及以上；首轮实际验收设备为 Xiaomi 14 / Android 16。

正式包使用 `cn.rainnotify.app`，预览包使用 `cn.rainnotify.app.debug`，可以并存。名称暂沿用原型界面；可在系统应用信息中核对包名。正式包首次安装后需要重新登录、输入 API Key 和授权，不会自动复制预览版的凭据。历史题目可从旧版导出 ZIP，再在新版导入。

先对照同目录 SHA256SUMS.txt 检查 APK，再用手机文件管理器打开 APK 并允许该来源安装。以后安装同签名且版本号更高的 APK 可直接升级，避免先卸载造成数据丢失。

打开设置，按需配置通知、声音、后台无限制及自启动。API 模式的密钥在手机输入；AI App 模式另需启用作答辅助和所选 App 的图文自检。登录后选择课堂并手动开启监听。入课可能记录签到；只有明确开启自动作答后才尝试提交。

内部验证阶段优先使用导入的历史题和“仅演练”入口。真实课堂提交、长时休眠与多品牌稳定性仍待现场验收，不能因安装成功视为稳定版。

出现问题可在设置的通知与诊断页导出本 App 诊断报告；其中不应包含登录票据、API Key 或原始题目。不要通过聊天发送密钥。
