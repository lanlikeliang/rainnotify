# 雨课堂助手：正式版安装与使用

v0.1.3，VersionCode 25，最低 Android 16（API 36），适用于普通版雨课堂。正式签名包名为 `cn.rainnotify.app`，可与 `.debug` 预览版并存。

[直接下载 APK](https://github.com/lanlikeliang/rainnotify/releases/download/v0.1.3/RainNotify-0.1.3-25.apk) · [最新版发布页](https://github.com/lanlikeliang/rainnotify/releases/latest) · [完整功能和配置说明](../README.md)

## 安装与升级

核对同目录 SHA256SUMS.txt 后，用手机文件管理器打开 APK 并允许该来源安装。已有正式版直接覆盖升级，不要先卸载；账号、API 配置与仍保存在本机的题目会保留。首次从独立预览版迁移，需要在正式包内重新授权、配置密钥及通知。

旧版本已自动清理的题目、未逐题保存的答案无法恢复。仍存在的题目会出现在课堂归档中，缺少课程名的旧记录显示历史课堂编号；旧版最后一题的结果可迁移。新版不再自动按最近 20 题或 80 MiB 清理课堂记录；存储空间仍受手机限制。

## 使用

1. 课堂 → 当前账户，生成授权二维码，在微信授权后返回。
2. 用微信扫描老师的课堂二维码，以微信提示确认入课。返回当前课堂，刷新并选中同一课堂，点击“我已扫码，连接此课堂”。界面经服务器握手后显示“课堂已连接”。课堂选择保留，避免连接到另一节同时进行的课。获取监听凭据的接口仍可能刷新签到记录，确认框会说明；App 的已连接状态不能证明签到成功。
3. 设置 → 通知与声音，允许通知，开启题目和结果提醒的声音；在系统中检查通知音量、静音 / 勿扰、悬浮及锁屏通知。设置 → 后台运行，将本 App 省电策略设为“无限制 / 不限制”，允许后台联网与本 App 自启动。菜单因品牌而异。无需安装 AI App、配置关联启动或无障碍。
4. 选择发题通知即可接收并保存题目。自动答题需先配置 DeepSeek API Key，并通过所选模型自检。Flash 支持图文；V4 Pro 仅文字，含图题明确失败并提示改用 Flash，不自动切换模型。
5. 课堂页显示最新题的收到时间、题型、AI 答案与处理状态；点击查看题干、选项和可放大的原图。“已提交 · 雨课堂已确认”才代表收到提交确认，结果待确认时到微信核对，不重复发送。
6. 题目 → 选择课堂 → 导出课堂复习笔记，保存单个 HTML 文件。用浏览器打开可离线阅读、折叠答案自测或打印为 PDF；图片嵌入文件中，不依赖雨课堂图片链接继续有效。

自动答题运行时，自检、修改模型或密钥不会改变当前模式，会提示先切回发题通知。主动切回通知或关闭可以取消后续处理，不能撤销服务器已收到的请求。

连续新题会排队；重连时尝试从服务器返回的时间线补收，已结束的补收题只归档。过期、网络不可用、题目不完整或提交结果不明确时不会强行提交。界面记录的时间为本机收到题目的时间，不冒充服务器发布时间。

本正式版沿用已验证的 24 版业务代码，更新版本标识与发布文档。24 版已通过 7 项 Xiaomi 14 隔离设备测试，原图、全屏查看、覆盖升级和课堂归档通过，用户确认导出保存成功。25 版的构建及云端检查记录随 Release 提供。多品牌、长时间熄屏和最新连续发题 / 重连能力仍需真实课堂验证。

设置 → 关于与帮助可导出脱敏诊断，诊断不包含题干、答案、登录票据或密钥。课堂复习笔记包含题目与答案，请按需要自行保存和分享。
