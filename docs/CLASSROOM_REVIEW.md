# 0.1.3-internal：课堂实测反馈修复

日期：2026-10-28。VersionCode 24。沿用正式包名与签名，未改变 DeepSeek 求解或雨课堂答案提交接口。

## 功能与原因

| 反馈 | 实现 |
| --- | --- |
| 课堂难以对应课程 | 读取课堂列表的 courseName，与 classroomName 组合；字段缺失时保留班级名，不编造课程名。 |
| 入课提示与结果不清楚 | 明确要求微信扫码。保留课堂选择用于指定监听目标，服务端握手后才显示已连接。扫描/签到以微信为准；获取凭据仍使用已有已验证接口，可能刷新签到记录，点击前明确提示。 |
| 自检后自动档变通知档 | 统一拦截运行中自检、模型切换、密钥保存/删除，保持原模式；只在主动切回通知/关闭后允许修改。API 实际不可用等故障降级保留，并给出原因；结束或故障清理遗留的 automaticRequested 状态。 |
| API 可用但页面原图不可用 | BitmapFactory.Options 默认采样值未设为正数，旧循环可能除零；现在从 1 开始计算有界采样。原始文件不改动，保留点击和手势放大。 |
| 按课堂复习 | 两种开启模式均先采集保存。取消默认 20 题/80 MiB 自动淘汰；以 lessonId 分组，不按显示名称或登录 Cookie 分组。逐题保存答案、模型、状态；重新登录同课不会拆分归档。 |
| 导出目的 | 单文件 UTF-8 HTML，包含按时间排序的题干、选项、内嵌原图、可折叠 AI 答案和状态，支持离线阅读及浏览器打印。清除脚本、远程链接和内部标识，包含内容的学习文档不当作诊断上传。 |
| 最新题位置与返回 | 课堂页仅显示收到时间、类型、答案、状态，可进入详情；题目页是按课堂归档。保存页面来源栈，从课堂/设置/课堂题目列表进入后各自原路返回。 |
| 连续发题与断线 | 旧版忙碌时直接忽略新题；现在按接收顺序排队，去重并沿用原接收时限，结束后再启动下一题。题目采集不阻塞长连接。重连时间线仅补收初次连接后未见的新题；已结束题只归档，不能提交。 |
| 图标比例 | 黑白图案不变，使用原生 adaptive-icon 的黑底与 18dp 前景边距，避免旧单层图标被桌面再次缩小。各厂商裁切与实际大小仍需真机比较。 |

## 回归与验证

- JVM 回归覆盖课程元数据兼容、正数图片采样、超过 20 题的保留、逐题答案持久化、同课分组、跨课导出隔离、原图内嵌/隐私过滤、主观答案导出、连续题排队/取消/时限、重连补收及去重；保留五题型与提交确认保护测试。
- Android 设备测试增加来源导航和自动模式自检保护；测试包只用合成数据与隔离应用包。编译通过不计为设备测试通过。
- 合成 HTML 样例在桌面浏览器检查原图、题干、选项、单选与主观答案排版及折叠交互；不是 Android 原生界面验收。
- 每个安装包携带构建收据、签名指纹及 validation-summary.json；以对应记录为准，不把旧版设备或课堂测试算作本版通过。

## 明确限制

没有连接时服务器未返回的事件不能凭空恢复；首次进入的既有时间线不自动答题。重发同一个题目 ID 与服务器回放仍可能无法区分，保留去重；过期、网络中断、进程被系统杀死及模型慢响应仍可能未提交。提交结果不明确时不自动重试。

题目收到时间不等于精确发布时间，补收会标注；当前协议没有经过验证的统一发布时间字段。旧版已清理的原图/题目以及未保存的旧答案不可恢复。没有教师标准答案时只展示 AI 答案，不能作为正确率保证。

当前保留单模块、现有依赖版本和提交接口。产品不重新引入 AI App 自动化、历史演练或开发者调试入口。

图标层尺寸参考 [Android 自适应图标说明](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive)。
