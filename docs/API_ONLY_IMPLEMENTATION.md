# 0.1.1-internal：API 正式界面实现记录

日期：2026-10-27。此版本是正式版产品路线的内部验证包，不标记为 1.0 稳定版。

## 实现

- Compose + Material 3，底部仅课堂、题目、设置。课堂页固定显示账号、课堂、当前模型；首次使用不切换到另一套布局。
- 灰色带轮廓胶囊轨道、白色浮起选中块，三个互斥档位始终可见：关闭、发题通知、自动答题。连接确认后才显示运行；连接中仍可关闭，缺项时列出直达设置入口。
- 发题通知不依赖 API；自动答题要求已保存密钥且当前配置通过图文自检。切回通知/关闭取消可取消任务，已发出的提交等待回执且不重复发送。API 权限/余额/图文参数阻断性错误使自动档降为通知。
- 手机直接调用 DeepSeek `deepseek-flash`。密钥加密保存不回显，自检仅用合成图文且不提交课堂；更换 Key 后自检失效。
- 题目页只跟踪最新一题，显示题干、选项、可放大的图片、答案和提交结果；旧题迟到结果不覆盖新题。
- 删除 Kimi/DeepSeek/豆包 App 的适配、无障碍、关联启动与解锁页面；删除历史演练、导入导出和模拟触发的用户入口。保留旧数据文件和内部格式测试，不清除已有账号/密钥/题目归档。
- 设置集中管理雨课堂授权、API、通知声音、本 App 后台运行和脱敏诊断。后台联网仍依赖系统及厂商策略，通知许可不能替代后台运行保障。

## 已验证

- Debug 与未签名 Release 可在 JDK 17 / AGP 8.13.2 / API 36 下编译，严格依赖校验开启。
- JVM 合成回归 116 项通过，包括五题型请求/提交、防重复提交、取消/截止时间、API 网络与格式异常、三档前置条件及新旧题结果归属。
- Python 9 项通过，覆盖脱敏诊断统计与正式清单组件边界。
- Release Lint 无错误、无新增警告（剩余 10 项此前审核过的提示）；未放宽 Lint 基线。
- 本次新增 175 个依赖摘要与 Google Maven / Maven Central 的官方 HTTPS 摘要逐项匹配；Gradle 仍校验 SHA-256。
- 正式清单仅一个用户 Activity 和两个非导出服务；仅查询微信用于账号授权，不再查询 AI App。
- 独立 Smoke 包及 4 个 Compose 设备测试已编译通过，未执行到设备。Release 移除依赖库引入的 shell 性能测试接收器，保留自动性能配置初始化。

## 尚未验证

- 本轮没有运行设备端测试，没有安装覆盖手机，也没有使用真实账号/API Key/课堂。
- 提供 Compose Preview 与独立包的 4 个 Compose 设备测试；编译测试包不等于执行通过。当前电脑尝试启动 Android Studio 后未出现可控制窗口，未记录实际 Preview 截图。
- 需要实际查看三档控件、字体放大、长课堂名、扫码返回、软键盘与图片放大；需要重验切档取消、后台通知及熄屏 API 提交。
- 当前五题型能力沿用原有协议；合成测试不能证明真实雨课堂接受所有题型。分组、非文字主观、个人意愿投票等不支持的场景继续明确提示。
- 多品牌/长时休眠、正式包同签名升级保留数据仍需单独验收。

发布包包含安装说明、摘要、签名信息和构建收据。以收据里的提交号、dirty 标志、校验选项为准；不把旧版本课堂实测结论直接视为本次界面重构验收。
