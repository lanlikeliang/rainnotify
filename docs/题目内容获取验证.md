# 题干、选项和原图：0.0.10 实课校验

日期：2026-10-12（北京时间）。本阶段只完成题目内容获取与查看，AI 求解及答案提交尚未接入。

后续 0.0.11 已加入单题与最近题目 ZIP 手动导出，参见 [志愿者安装与采集说明](志愿者安装与题目采集说明.md)。下方 0.0.10 的安装记录属于此前验证。

## 使用步骤

1. 打开“普通版雨课堂登录与课堂监听”，在微信正常入课后选择本节课堂，手动开始监听。
2. 等待下一道新题。通知仍会立即发出，随后在独立工作线程获取内容，不等待图片下载再提醒。
3. 点击通知或其“查看题目”按钮，查看这道题的题型、题干、选项和图片。
4. 点击“放大查看”后，可双指缩放、单指拖动。返回题目即可继续查看其他附图。
5. 对照微信雨课堂检查内容。若出现图片或网络错误，可在仍监听同一课堂时点击“重新获取本题内容”。
6. 首页和登录监听页都有“最近题目 · 题干、选项与原图”入口；下课后可离线查看已经保存的内容。

当前只获取监听开始后收到的实时新题，不补抓初始连接中的历史题。旧版已收到的题目只有提醒记录，没有原题缓存，升级后无法从旧诊断记录还原。

## 请在下一次自然发题后反馈

- 大致时间、题型，以及是从通知还是最近题目列表打开。
- 题干是否完整；如果文字区提示“无独立文字题干”，原图中是否完整包含题干。
- 选项数量和标签是否与微信一致；选项正文可能本来就绘制在课件原图中。
- 原图和选项附图是否显示，放大后能否看清。
- 如失败，请提供界面上的错误描述；无需发送账号、Cookie 或登录二维码。

例如：“14:30，单选；原图完整，四个选项 A–D 都有，文字区只有字母，选项内容在原图里，与微信一致。”

题型为接口字段的展示映射，尤其判断题的真实字段仍需样本核验。当前不会把判断题的 A/B 或 1/0 猜成答案，也不保存或显示服务端返回中的参考答案、解析或本人作答结果字段。

## 本机保存与数据范围

- 默认保留最近 20 题，题干、选项及原始图片保存在 App 私有的 noBackup 目录，总量上限约 80 MB；达到上限会清理较旧记录。
- 详情页缩略图和放大图会按设备内存限制解码显示，保存的下载原文件不被压缩改写。
- 可在“最近题目”中清空本机题目与图片；清空不会停止课堂监听，之后的新题仍会保存。
- 本阶段不向 AI 或自建服务器上传题目。登录凭据继续使用原有加密保存方案；题目缓存依靠 Android 应用私有目录隔离，并排除系统备份。
- 通用诊断仅记录题型、选项数、图片数、成功下载数、是否有文字题干及错误阶段；不写题干、选项正文、图片 URL、账号或凭据。

## 实现与边界

- LessonSignal.Question 保留课堂、课件、题目及页面定位信息。继续沿用当前会话内去重规则；同题重复发布仍不会新建第二条提醒。
- RainApi.question 只发起已登录会话的课件 GET 请求，使用当前监听所用的 RainApi。取题与重试不调用入课、签到、答案或补交接口。
- 通过 problem.problemId 精确选择页面，存在多个匹配或页面标识冲突时返回错误，不仅按页码猜测。
- 从 body、bullets / options 和 cover 提取内容；题干和选项中的 HTML 图片单独获取。只存本题必要字段，不保存整套课件响应。
- 页面以原生文字和图片组件展示，不运行 HTML JavaScript，也不自动打开题干链接。
- 图片使用独立 HTTP 客户端，无雨课堂 Cookie 或 Authorization；允许已核对的 yuketang.cn、xuetangx.com 域名及子域，重定向逐跳校验。未适配的 CDN 来源会明确报错，需根据实际样本补充验证。
- 单课件响应上限 8 MiB；单图 10 MiB、每题最多 12 张图片、累计下载约 32 MiB。超限或无法解码会标为未完成，避免静默当作完整内容。
- 停止监听后保留已获取内容；重试只在同一课堂的监听会话仍有效时可用。进程重启后仍可读缓存，未完成任务会显示中断，不自动入课恢复。
- 每个通知使用独立的本地题目 ID 与 PendingIntent data，避免多个通知全部跳到最后一道题。
