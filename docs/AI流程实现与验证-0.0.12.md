# AI 作答试验版 0.0.12

更新日期：2026-10-16。Kimi 3.1.3 的单选、多选图文自动演练各通过一次；真实课堂提交尚待验收，不能据此宣称线上完整闭环已经通过。

## 使用范围

普通版雨课堂、Android 16、独立辅助 App、纯手机运行。每题由用户主动启动。通过已登录的 Kimi App 处理图文；用户需手动开启“雨课堂 · Kimi 作答辅助”，保持解锁亮屏，完成前不切换其他 App。

历史题：最近题目 → 选择一题 → AI 演练与本题作答 → 仅演练本题。也可在最近题目中导入本 App 导出的完整样本 ZIP。导入记录永久标为离线，仅用于演练，不能用于课堂提交。

新题：通知上的“AI 作答并提交”只处理该通知绑定的一题。真实提交目前仅开放单选、多选的候选协议。判断题可演练，需补充真实样本及提交协议验证后再开放。

## 已实现的流程与约束

1. 从题目缓存复制本题全部图片，确保求解过程中缓存清理不会替换输入。缺图、下载失败或选项没有可靠标签时停止。
2. Android 分享 Intent 传送原图；无障碍适配器仅在用户启动的任务期间读取 Kimi、填入题目、点击发送和读取答案。未启用权限时不自动操作。
3. 要求输出带本次随机任务标识的 JSON，仅接受合法选项、合法单选/多选数量及完整最终回答。不采纳旧聊天或示例答案。
4. 演练模式没有雨课堂提交网关。真实模式先核对当前监听、题目内容、账号作答状态和服务端计时，模型完成后重新核对。
5. 写入持久化提交尝试记录后才允许发送一次 POST。超时、断网或不明回执标为“待核对”，不会自动重发；进程重启不会恢复未完成提交。
6. 任务运行目标上限约 85 秒，求解最多 60 秒，实际提交必须早于服务端截止时间。用户晚点击不会重置课堂作答期限。提交发出后停止按钮不能撤回请求。

## 协议核对依据与未决事项

本地保留的雨课堂官方公开前端脚本包含 `/api/v3/lesson/problem/answer`，字段为 `problemId`、`problemType`、`dt`、`result`。结果标签排序，与前端行为一致；成功与“已有作答”分别处理。

课堂计时通过 `probleminfo` 获取，使用服务端 `now`、`dt`、`limit` 计算，并扣除请求往返时间，避免依赖手机墙上时钟。当前实现要求回包能用 `msgid` 与题目 ID 对应请求；真实服务器是否回显 `msgid` 尚待自然课堂验证。无法关联时停止提交，不能将模拟服务器通过等同于线上协议通过。

账号已答状态必须有可识别的 `result` 字段；缺少该字段视为未知，停止提交。题目内容变化、连接中断、提前收题、已经作答、选项非法均不继续提交。同题重新发布不自动清除提交尝试记录。

## 数据处理

调试注意：Android 官方说明 UiAutomation 默认会抑制已有无障碍服务，除非显式采用 `FLAG_DONT_SUPPRESS_ACCESSIBILITY_SERVICES`。自动作答进行中不使用默认的 `uiautomator dump`，避免测试工具本身取消任务。[Android UiAutomation](https://developer.android.com/reference/android/app/UiAutomation#FLAG_DONT_SUPPRESS_ACCESSIBILITY_SERVICES)

仅本题文字及原图发送给用户登录的 Kimi 服务；不传递雨课堂 Cookie、登录票据或完整课件响应。分享授权只覆盖本次原图文件，任务结束后撤销授权并清理临时副本。通用诊断记录阶段、时间及本机随机任务 ID，不记录题干、答案或登录凭据。真实样本留在本地且不打包进 APK。

若图文导入或最终答案回读无法稳定完成，按用户授权转为手机直连 GLM 视觉 API。API Key 届时在手机设置中输入，不在聊天、源码或日志中提供。当前尚未启用该后备路线。
