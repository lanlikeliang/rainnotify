## 1. 项目定位与已发布基线

伞课堂是面向普通版雨课堂的独立 Android 辅助 App。用户授权本人账号、用微信扫码入课并选择课堂后，App 监听新题、保存题干选项及原图，可仅通知，也可调用本人配置的 DeepSeek API 作答并尝试提交，课后按课堂导出复习笔记。无需部署项目服务器。

## 2. 功能与前置条件

### 使用流程

1. 在同一套课堂／题目／设置页面中完成首次配置，不引入独立的新手版界面。
2. 允许本 App 通知，检查题目／结果渠道、通知音量、勿扰与悬浮通知；本 App 省电策略设为无限制并允许自启动、后台联网。
3. 生成账号授权二维码，在微信识别并确认，回 App 获取授权状态。账号登录不等于已参加课堂。
4. 在微信扫描教师的课堂二维码入课，回 App 刷新、选定课堂，点击“我已扫码，连接此课堂”。选择课堂保留，用于明确监听目标。
5. 服务端确认连接后才能视为监听建立。连接凭据仍通过现有接口取得，可能刷新签到记录；App 提示此副作用，签到结果以微信为准。
6. 在有轮廓的胶囊三选一控件选择模式。仅自动答题要求有效 API Key 和所选模型自检通过。

| 模式 | 行为 |
| --- | --- |
| 关闭 | 停止监听与后续自动处理，仍可看本地归档和设置。 |
| 发题通知 | 接收事件、保存题干选项原图、发系统通知，不要求配置 API。 |
| 自动答题 | 包含通知和采集，在本次有效课堂会话内排队求解、校验、尝试提交并记录结果。 |

API 路线可在熄屏时工作，不依赖手机 AI App、无障碍、链式启动、悬浮窗或代输锁屏密码。但 API 不能代替系统对本 App 后台运行和网络的许可。单次监听最长 4 小时，收到下课消息会结束；不是开机后无人确认就自动进入课堂的常驻服务。

### 模型与题型

当前代码内置 `deepseek-flash`（图文）和 `deepseek-v4-pro`（纯文字），请求由手机发送至 DeepSeek 官方接口。模型能力是本版本实现快照，扩展或更新前须重新核对服务商官方说明及实测，不能只按名称推断能力。

- Key 在手机输入，由 Android Keystore 加密保管；自检会真实调用 API。
- 自检按当前模型／配置区分。Pro 遇图片明确失败并提示切 Flash，不擅自剥掉图片或替用户切换模型。
- 自动运行中拦截自检、模型切换、保存／删除 Key，提示先主动切回通知或关闭；不会因点自检静默改变模式。真实 API／后台故障仍可能明确降级为通知。
- 支持单选、多选、投票、填空、文字主观题；主观默认 1–3 句、最多 300 字符。填空保持空格顺序与重复值。
- 主观题要求绘图／音频、投票涉及个人偏好等不适合代答时停止。独立判断题 type 6 的线上提交未验证，不因内部解析兼容而宣传支持。

### 页面与复习

课堂页展示账户、课程／班级、当前模型、三档模式，以及最新题收到时间、类型、AI 答案和处理状态。收到时间不是教师精确发布时间，补收应注明。移除了重复状态标语，不再加“最近处理”区块。

题目页按课堂保存全部已收到的题，两个开启模式都采集。详情显示原图并可全屏查看；以课堂为单位导出单个 UTF-8 HTML，嵌入图片并折叠 AI 答案，支持离线复习和浏览器打印 PDF。当前不再自动按最近 20 题／80 MiB 淘汰，仍受手机存储限制；旧版删除或未保存的资料无法恢复。

账户、课堂、模型等子页按入口返回；从课堂进入应回课堂，从设置进入应回设置。关于与帮助显示伞课堂名称、版本、GitHub 链接和脱敏诊断导出。AI 答案不等于教师标准答案。

## 3. 架构、数据流与代码入口

保留单一 `app` 模块：Kotlin + Compose 1.9.5 + Material 3 1.4.0 + Activity Compose 1.11.0；AGP 8.13.2、Gradle Wrapper 8.13、Kotlin 2.3.21、JDK 17、Build Tools 35.0.0。版本与校验来自 [Version Catalog](../../../android-app/gradle/libs.versions.toml) 和 Gradle 依赖校验文件，不沿用原型的临时盘符构建法。

主链路：账号授权 → 选课／凭据 → 课堂长连接握手 → 新题事件 → 题目与图片采集／通知 → 自动队列 → 准备完整题目 → 求解前状态校验 → DeepSeek → 严格解析答案 → 提交前重新校验 → 持久化提交占位 → 单次 POST／回执 → 逐题状态和课堂摘要更新。

题目存于 App 私有 `noBackupFilesDir/questions-v1/`：逐题 `question.json`、原图文件和 `answer.json`。按 `lessonId` 分组，不按课程显示名或 Cookie 分组；课程名缺失不编造。`last-answer-task.json` 是当前任务状态，不替代逐题归档。导出复习内容与脱敏诊断是不同产物，不能把复习文档当作可公开日志。

### 必须保持的行为边界

- 求解前和提交前都获取新状态：账户已答、题目内容变化、课堂切换／断开、收题、时限不足时不提交旧答案。
- 内部总预算为从任务接收时计 85 秒，模型请求最多 60 秒，并留提交余量；还受服务器题目截止时间约束。排队不重置原时限，不承诺每题都在 90 秒内成功。
- 提交前持久化防重占位。`UNKNOWN` 表示可能已送达，不自动重发；已开始的提交不可撤回，等回执。不能通过清空 journal 或放宽验证来提高表面成功率。
- 题目采集不阻塞长连接。首次连接已有时间线不自动答；重连只补收本次连接后未见记录，已结束题只归档。同 ID 重发仍可能与回放难以区分。
- 队列与监听会话在进程内运行，归档和提交 journal 持久化；进程被杀不意味着任务能恢复执行或保证零漏题。
- Manifest 使用两个非导出 `specialUse` 前台服务；Release 非调试包，无旧无障碍服务、AI App 查询或 USB 测试页面。`src/debug` 仅保留只读题目比较入口。
