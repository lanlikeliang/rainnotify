# 参考答案与提交分离

2026-11-06，当前内部版本为 `0.1.4-internal / versionCode 27`。本次包含普通版、长江版、黄河版、荷塘版适配，沿用先选择服务器再登录的入口。

## 已落实的行为

- 已取得完整题目后，先用该次捕获的题干、选项和全部原图请求 AI。生成答案后立即持久化并显示，再进行自动提交检查。
- 自动提交比较题型、题干文字、选项文字与映射、作答数量规则和图片结构。图片地址仅用于下载和脱敏的地址变化标记。
- 比较图片实际字节。字节不同再比较完整解码像素，相同像素可以通过。比较全部图片共用最多 6 秒网络预算，解码上限为每张 4194304 像素。
- 下载失败、超时、无法解码、超过像素上限或不同的 GIF 数据，按用户授权退回文字及结构核对。诊断记录 `image_comparison` 的 match、different、unavailable 固定状态。
- 确认图片实际变化或题干、选项变化时停止自动提交，参考答案及其依据的题目和原图继续保存在本机。账号已答、时限不足、复核失败也保留参考答案。
- 教师延时走独立时间状态，自动提交使用求解完成后查询的最新剩余时间。排队后的参考答案生成按开始处理时计时。课堂结束时允许已经开始的参考生成完成。用户主动关闭自动答题仍可停止当前求解。

## 课堂页面与手动提交

最新题目展示题型、发题时间、课件原图、参考答案和提交按钮。时间采用本机收到题目的时刻，界面标注“本机接收”。原图可以点击放大。文字题展示题干和选项。

点击“提交参考答案”会展示对应服务器、题型、时间和答案，用户点击“已核对，直接提交”后发出一次请求。手动提交跳过远端题目变化、图片比较、剩余时间和已作答状态复核。

手动提交保留服务器、账号及课堂定位检查、答案格式检查和持久化防重记录。已发送、回执未知或已有尝试记录的题目显示核对提示。切换服务器或课堂后，须重新连接与记录对应的服务器、账号和课堂。回执状态与参考答案分别展示。

保存参考题目和原图快照，避免之后刷新课件把参考答案与新原图混用。旧版本归档仍可读取。自动与手动路径共用提交日志，多个日志实例使用共享锁，防止并发重复发送。
