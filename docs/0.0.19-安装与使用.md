# 雨课堂助手 0.0.19

适用：普通版雨课堂、Android 16。安装名称改为“雨课堂助手”，可直接覆盖之前的测试版，不需要卸载，原有题目和登录会话保留。此包为开发预览版。

## 第一次打开

1. 点首页底部“设置”。
2. “通知与声音”：允许通知，打开题目提醒的声音、横幅与锁屏显示。可以用模拟通知验证。
3. “本 App 后台运行”：允许“雨课堂助手”自启动，省电策略设为无限制；检查后勾选确认。系统未必能自动检测厂商全部设置，因此仍需手动确认。
4. 回首页点“登录 / 选择课堂”，生成微信授权二维码，用微信扫码授权，返回后选择课堂并确认入课监听。入课可能记录签到；若老师要求动态课堂二维码，仍须先扫码。

做到这里即可接收新题提醒并保存题干、选项与原图，不需要配置 AI。

## 使用 AI

“设置 → AI 作答方式与配置”可选择：

- **DeepSeek API**：输入自己的 API Key 并加密保存，通过图文自检后使用。无需安装 AI App，无需无障碍授权，可以在锁屏时处理题目。每次调用会发送题干、选项与原图，并按 DeepSeek 官方用量计费。
- **Kimi / DeepSeek / 豆包 App**：提前安装、登录，开启本 App 的“AI 作答辅助”，再做对应 App 的图文自检。无需让 AI App 常驻后台或为其设置自启动；执行时需要手机解锁，期间不要操作其他 App。

切换作答方式会关闭自动模式。在“题目”页先选择历史题并点击“仅演练”，确认可用后再用于课堂。API Key 不要发给项目负责人，不包含在安装包、题目导出或诊断报告里。

## 手动与自动

- 监听开启后默认只提醒、保存题目。
- 当前课堂的新题可以选择“开始 AI 作答并提交本题”。历史题、离线样本只能演练。
- 要自动处理后续新题，在首页开启“新题自动作答并提交”并确认。未监听或配置不全时，开关保持关闭，并提示应去哪里完成设置。
- 自动模式仅在本次课堂监听中有效。停止监听、下课或切换作答方式后关闭；App 进程被系统结束后需重新开启。
- 每次处理一道题，最多约 85 秒。新题到来时若上一题尚未完成，只提醒新题，不排队补交。可停止本题；已发出的提交不能撤回，回执不明时请去微信核对。

## 五种题型

单选、多选、投票按选项作答；填空按空格顺序填写；主观题默认简洁文字，1–3 句、不超过 300 字符。缺少必要题目规则、图片不全或无法可靠作答时停止，不发送猜测的提交参数。个人意愿调查不由 AI 代填。分组题请在微信完成，暂不自动代表小组提交。

新题型已完成协议与模拟校验，真实课堂显示与提交回执仍需现场核对；AI 给出格式正确的答案不代表答案一定正确。

## 采集与反馈

在“题目”里选择“导出最近题目 ZIP”或导出单题，再手动发送给项目负责人。内容包含题型、题干、选项、原图、空格数量与投票限制，不含登录会话和 API Key。图片本身可能含个人或学校信息，请检查后再发送。

问题反馈建议包括：版本、手机型号、发生时间、题型、使用 API 还是哪款 AI App、当时屏幕状态、页面提示。诊断导出位于“设置 → 通知与声音”。不需要提供密码、密钥或二维码。
